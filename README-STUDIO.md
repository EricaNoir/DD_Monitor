# DD Monitor Studio

DD Monitor 的交互改版。Windows 原生多屏播放器，增加昵称搜索、固定收藏头像栏和可折叠控制条，以及浏览器式固定弹幕列表。

界面颜色、字体、尺寸与图标共用 `studio/theme.py` 中的设计 token。组件约定和自动检查说明见 [设计约定](docs/DESIGN.md)。

## 使用

不会使用 Git 的 Windows 用户可从 [Releases](https://github.com/EricaNoir/DD_Monitor/releases) 下载便携 ZIP，完整解压后双击「启动 DD Monitor.cmd」，不需要安装 Python 或 VLC。分享请用原始 ZIP 或 Release 链接，不要分享使用过后包含 `user-data` 的文件夹。便携包由干净的 GitHub runner 构建，附带校验值与构建来源证明；完整说明见 `packaging/README-PORTABLE.txt`。

双击 `run-studio.cmd`。首次配置先运行 `setup-studio.ps1`，需要 Windows 64 位和 Python 3.10–3.13。

- 顶部 **+** 添加直播间。窗口上方固定一排收藏头像，可横向滚动，开播的排前面；点击头像勾选播放，头像旁实心 / 空心星切换收藏。取消收藏立即保存并同步侧栏，但头像留在本次窗口里供恢复，关闭后再打开才从横排移除。收藏是本机列表，不会自动关注 / 取消关注 B 站账号。
- 下方提供 **我的关注 / 全站搜索**。我的关注读取当前 B 站账号的完整关注列表，支持分页，输入昵称会搜索整个关注列表，清空搜索框返回全部关注。未开通直播间的账号仍会列出，不能勾选播放或收藏为直播间。全站搜索支持昵称、房号或链接，保留 **全部 / 已关注 / 未关注** 筛选；这一筛选仅作用于已加载的全站搜索结果。未登录、登录过期或查询失败不会冒充空关注列表或未关注状态。
- 左侧固定为 42 像素收藏头像栏，无折叠按钮和可拖动分隔栏；头像居中，左右与上下留白一致。悬停查看昵称，底部「+」添加主播。左上角显示当前账号的登录状态和昵称，点击可扫码登录或切换账号。
- 收藏及当前画面的开播状态每 30 秒批量刷新，正在直播的优先排列。已收藏且正在直播的主播自动填入空白或确认未开播的画面，不重复占位；全部画面都在直播时，新开播主播不会替换现有画面。已在画面内等待的主播开播后自动加载视频；网络失败或状态未知时保持原画面。点击已播放的主播只定位，不重载；新主播优先填入空白画面，画面已满时点击不替换已有直播。仍可拖入指定画面进行替换，支持 1 / 2 / 4 / 6 / 9 画面。
- 左侧栏同时标出当前画面内的所有直播间，切换布局、放大单个画面或关闭房间时同步更新，不再只高亮最后点击的一个。右键头像可「移除收藏」，正在播放的窗口继续保留。
- 左侧头像支持列表内拖拽排序，显示插入线，靠近上下边缘时自动滚动，顺序会保存。仍然优先显示开播主播；开播与未开播两组内按自定义顺序排列，自动补位也优先选择排在前面的已开播收藏。拖到右侧仍然播放到指定窗口。
- 左侧栏底部「↻」立即刷新开播状态，查询期间禁用，刷新后同步排序和自动补位；悬停可查看刷新是否成功。头像与画面工具栏的状态灯使用更醒目的绿色，未开播为灰色。
- 拖住小窗口顶部的主播名称栏，放到另一个窗口上即可交换位置，也可与空白窗口交换。视频、聊天记录和音量等设置随窗口移动，排列顺序自动保存。所有窗口使用统一边框，不显示选中高亮。
- 全局控制都位于顶部。统一线条图标提供暂停、静音、重连、音量、聊天、设置与添加等操作，悬停可看含义；布局和画质保留文字。顶部聊天图标或 `Ctrl+J` 控制所有直播间，每个画面也有独立聊天开关。
- 每个画面可以暂停、静音、调音量、独听、切换画质、重连和放大。**关闭键「×」固定在每个画面的右上角**，隐藏控制条后仍可使用；关闭画面会保留主播库中的收藏。
- 视频连接失败、断流会自动重连，连续失败按 3 / 6 / 12 / 24 / 30 秒退避；取流超过 45 秒、缓冲超过 25 秒、播放进度停滞 20 秒也会恢复。手动暂停或隐藏的画面不主动重连，关闭房间取消重试；未开播房间每 30 秒检查一次。重连保留音量和静音，不重置聊天历史；聊天连接异常退出也会自动重试。
- 每个画面顶部单行显示 **主播昵称 · 直播间标题** 和图标控制。过长标题省略，悬停看完整内容。移除了小窗口「添加或替换」入口；窄画面下的「⋯」只收纳音量、独听和重连。所有下拉选择从按钮下方展开。
- 每个直播间旁边都有独立的固定聊天列表，同时展示昵称、粉丝牌、内容和表情；粉丝牌使用淡紫色斜体，无灰色底块。每个房间保留最近 500 条消息。没有横向飘屏动画。新消息在底部追加，可关闭跟随或向上查看历史。
- 聊天列表也显示实时收到的礼物、大航海购买和 SC：礼物展示赠送者、名称和数量，SC 展示金额与留言；重复 SC 不重复插入，收到撤回通知后移除对应留言。连击汇总事件不会再作为一份礼物重复显示。
- 每个聊天区顶部提供 **全部 / 聊天 / 礼物 / SC** 标签；切换只筛选显示，不丢弃其他消息，各画面的筛选设置会保存。底部输入框支持 Enter 或发送图标发送普通弹幕；使用当前扫码登录账号，按房间返回的字数限制校验，失败保留草稿，不自动重发。发送成功后自动滚到最新消息，不显示“已发送”。聊天底部不再放连接状态和回到最新按钮；发送失败通过浮动提示说明，不挤动输入框和聊天区。
- SC 同时以半透明小卡片显示在对应视频左上角：宽 130 像素、最小高度 40 像素，长留言自动撑高；不显示倒计时、进度条或「·」。显示时长为原时长的 1/10，至少 6 秒；长留言按每秒约 5 字加 2 秒起读时间延长。从首次收到开始计时，未来 SC 等到开始时再显示，重复消息不续时。连接时只补取服务端尚未过期的 SC；撤回立即移除，切换标签、隐藏聊天或暂停视频不延长时长。浮层不抢焦点、不拦截鼠标，最多展示最近 3 条（小画面会减少），其他 SC 可在 SC 标签查看；聊天历史里的 SC 不会因为浮层到期而消失。
- 点击每个画面顶部的 **礼物图标** 打开内置送礼 / SC 面板。扫码登录后读取该房间的可用礼物、SC 档位和电池余额；选择礼物数量或填写留言，确认主播、付款账号和总电池数后发送。不依赖浏览器页面，也不会自动充值。当前支持普通电池礼物及服务端提供的 SC 档位，不包含盲盒、活动特殊商品、大航海购买、自定义 SC 金额和定制图片。
- 付款前重新核对房间、账号、最新价格及余额；价格变化需重新确认。支付请求不自动重试，结果不明确时会停止本次面板的再次发送，请先核对余额和直播间记录。SC 保留订单号供复制，可在面板中查询留言审核结果；订单提交不代表留言已经展示。
- 拖动各房间的视频与聊天之间的分隔线调整栏宽；顶部「设置」统一调整文字大小、昵称和自动跟随。发送弹幕后自动回到最新消息。
- 底部不再占用指引或全局控制空间。操作指引和快捷键集中在顶部 **i** 图标里：`Ctrl+K` 添加，`F11` 全屏，`Esc` 返回。

登录通过 B 站 App 扫码。B 站未登录连接可能返回打码昵称；软件显示服务端实际给出的昵称，不猜测身份。登录和界面配置仅保存到已被 Git 忽略的 `user-data/`。若相邻目录有本人的 `DD-Monitor/app/utils/config.json`，可读取其中已有登录状态。不会修改旧版配置。

这是独立的新界面入口；仓库保留旧版源代码。旧版的录制、翻译、礼物榜等功能暂未迁入 Studio。弹幕区展示实际收到的消息，没有模拟浏览器观众榜。

## 开发与验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests\live_smoke.py
.\.venv\Scripts\python.exe tests\live_ui_smoke.py
.\.venv\Scripts\python.exe tests\tls_smoke.py
.\.venv\Scripts\python.exe tests\avatar_smoke.py
.\.venv\Scripts\python.exe tests\audio_smoke.py
.\.venv\Scripts\python.exe tests\audio_startup_smoke.py
.\.venv\Scripts\python.exe tests\reconnect_smoke.py
.\.venv\Scripts\python.exe tests\payment_read_smoke.py
.\.venv\Scripts\python.exe tests\chat_features_read_smoke.py 22603245
.\.venv\Scripts\python.exe tests\followings_read_smoke.py
```

第一条离线验证面板开关、宽度/记录保留、设置保存、房间切换、异步过期结果和字号等行为。生成 `.qa/` 下的界面预览，预览使用明确标注的示例聊天。第二条是主动联网的只读验证，检查搜索、真实解码和弹幕接收，不发送消息，不输出登录信息或视频鉴权 URL。

`live_ui_smoke.py` 验证两个真实直播间同时播放、分别显示消息和独立开关。`tls_smoke.py` 验证真实 HTTPS 图片加载。Windows 启动时仅在当前进程内隔离 DLL 搜索路径，Qt 使用 Windows Schannel TLS 后端，避免宿主程序的 OpenSSL DLL 污染；不修改系统 PATH 或关闭证书验证。

`avatar_smoke.py` 验证真实主播头像下载及缓存，并生成固定头像栏和收藏快速选择的预览。

`test_payments.py` 使用模拟支付响应验证金额单位、实际发送参数、取消确认、价格变化、余额不足、SC 字数、重复点击和网络超时。`payment_read_smoke.py [房间号]` 使用本机登录状态只读获取价格与余额，并接收 25 秒真实直播消息；脚本禁止 requests 发出任何 HTTP 写请求。实际扣电池发送未作为自动化实测的一部分。接口依据与限制见 [INTERACTION-API.md](docs/INTERACTION-API.md)。

`test_chat_features.py` 与界面回归测试验证弹幕发送参数、失败保留、过期回调、分类筛选，以及 SC 到期/撤回/隐藏窗口等行为。`chat_features_read_smoke.py [开播房号]` 联合验证真实视频解码、接收、字数配置和 SC 浮层，禁止 HTTP 写请求，不代发测试弹幕。

`followings_read_smoke.py` 只读验证真实关注列表的首页与末页、关注内搜索和新添加窗口的头像布局，不改变 B 站关注关系。对应离线测试还覆盖取消收藏后的延迟移除、侧栏右键操作、无直播间账号和侧栏可见房间标记。

`audio_smoke.py` 使用本地无声 PCM 验证真实 Windows 音频输出的独立静音、音量和播放进度，不访问网络。`audio_startup_smoke.py` 验证音频输出重建时以零音量启动，以及多个窗口首次播放、重连时恢复各自保存的音量和静音状态，不发生音量越限。Studio 使用 DirectSound 的独立缓冲区控制每个窗口，避免 VLC MMDevice 的共享会话静音/音量互相覆盖；音量设置成功后才允许解除静音，启动补设完成后停止快速检查，正常状态轮询不会重复写入未改变的音频设置。音频实现可参见 VLC 的 [MMDevice](https://github.com/videolan/vlc/blob/3.0.x/modules/audio_output/mmdevice.c) 和 [DirectSound](https://github.com/videolan/vlc/blob/3.0.x/modules/audio_output/directsound.c) 源码。
